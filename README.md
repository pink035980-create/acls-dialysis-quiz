# ACLS 透析急症互動測驗系統 (AHA 2025/2026 Guidelines)

本系統依據 **美國心臟學會 (AHA) 2025/2026 年最新 ACLS 指引** 與 **台灣 ACLS 聯委會核心題庫** 打造，專為急診、加護病房與血液透析中心同仁設計的實戰複習測驗工具。

## 🌟 核心特色
1. **全寬度心電圖動態示波器**：60 FPS 平滑連續滾動走紙，精確擬真醫用紅色毫米方格（PSVT 220bpm 窄 QRS、VF、Afib、3度 AV block 等）。
2. **20 題高頻急症模擬題庫**：融入高血鉀急救、不穩定型 Afib/Afl 初始電擊上調 200J、高危透析失衡等變革，全面採用經典複選組合題型。
3. **即時雷達圖與成績分析**：百萬級六大維度雷達分析，評估學員急救知識弱點。
4. **多元成績匯出**：支援 Excel 格式 CSV 下載、A4 證書直接列印，與 JSON 檔備份閱讀。
5. **AI 智慧臨床診斷**：整合 Google Gemini 2.5 模型，提供專屬臨床弱點與處置建議。
